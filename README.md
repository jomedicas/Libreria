
Landing page moderna para una librería virtual desarrollada con HTML, CSS y Bootstrap.

es una página web responsive diseñada para mostrar un catálogo de libros de manera elegante y moderna.  

El proyecto incluye:
- Navbar responsive
- Hero section
- Catálogo de libros
- Formulario de contacto
- Footer informativo
- Diseño adaptable a dispositivos móviles

---
Tecnologías Utilizadas

- HTML5
- CSS3
- Bootstrap 5
